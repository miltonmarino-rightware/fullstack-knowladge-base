## Base — R18, MDN Learn

[MDN Learn Web Development](https://developer.mozilla.org/en-US/docs/Learn_web_development): tutoriais públicos em inglês, com fundamentos e módulos posteriores de frameworks. A nossa ordem proposta é HTML semântico → CSS/layout → JavaScript/DOM/eventos → acessibilidade → ferramentas/frameworks segundo necessidade.

Perguntas: como escolher elementos pelo significado? Como chegam eventos à lógica? Como verificar operação por teclado? A existência de módulos React corrige a descrição demasiado restrita do relatório.

## Aprofundamento — R08, web.dev

[Learn Accessibility](https://web.dev/learn/accessibility) oferece percurso temático. [Animation and motion](https://web.dev/learn/accessibility/motion/) é uma unidade concreta para relacionar movimento e acessibilidade. Índice e unidade consultados; exercícios não executados.

Usar para aprofundar lacunas do percurso MDN, sem repetir todas as introduções. A seleção não substitui uma formação completa em design de interação ou motion.

## Produção proposta

Uma ficha por unidade: mecanismo do navegador, necessidade do utilizador, exemplo, limites de testes automáticos e perguntas em aberto. Qualquer comparação entre interface com/sem framework deve controlar requisitos, conteúdo e ambiente; não pressupor vencedor.

Pendências: percurso aprofundado de design; desempenho com medições; série concreta de especialista em CSS; ligação entre TypeScript e execução no navegador. Tipos ficam no [pilar Linguagens](../linguagens/percurso-formacao.md).
